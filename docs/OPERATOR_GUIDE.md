# Operator guide

1. Inspect and clear the chamber and collection boxes.
2. Open the dashboard and run **Initialize**.
3. Resolve every preflight failure before starting automatic mode.
4. Use **Stop after current** for normal shutdown.
5. If no fruit is detected, inspect the reservoir before retrying feed.
6. Use **Software E-stop** when immediate software safe-state commands are required, then physically inspect and reinitialize.
7. Enter Manual or Maintenance only when automation is stopped.
